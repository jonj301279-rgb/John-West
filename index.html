Sobre o projeto

AVISO DE PARÓDIA

Este site reúne obras criadas como paródias e experimentos com inteligência artificial. O conteúdo é feito com finalidade humorística, criativa e de entretenimento. Não representa lançamentos oficiais, nem deve ser confundido com obras, artistas, gravadoras ou canais oficiais.

Importante: nomes, imagens, personagens, músicas ou referências de terceiros podem aparecer apenas no contexto da paródia. Respeite os direitos dos respectivos titulares e as regras das plataformas.

PAINEL RESTRITO

Administrador

Somente o administrador pode adicionar, editar ou excluir músicas. O PIN protege a interface neste navegador. Para segurança real em um site público, seria necessário um backend.

YouTube automático: para o site conseguir buscar a capa real das playlists e sincronizar títulos/datas, informe uma chave da YouTube Data API v3. A chave fica salva apenas neste navegador. Sem chave, as músicas ainda usam a thumbnail padrão do vídeo quando o link permite identificar o ID.
Para segurança, restrinja a chave no Google Cloud Console ao seu domínio quando publicar o site.
